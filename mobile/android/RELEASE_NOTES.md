**OksaSDR for Android — beta 32.** A FlexRadio client for Android phones and tablets, built on the [AetherSDR](https://github.com/aethersdr/AetherSDR) engine: the same app as on the iPhone and iPad (TestFlight), from the same code.

### New in beta 34
- **The slice volume beside the speaker icon** on the info panel (e.g. 🔊 50): a new slice plays at 50, and a tap on the speaker sets it (thanks Jae and Jeff for the low-audio reports).
- **A log line when the app stops answering:** how long and what was going on, kept even if Android closes the app, so freezes on slower tablets can be found (thanks Kurt DL5EAG).

### Still new from beta 33

### Install or update
1. Download `OksaSDR-android-beta34.apk` below on the phone (about 150 MB).
2. Open it; allow installing from your browser or file manager when Android asks. If Chrome keeps the download waiting, open ⋮ → *Downloads* → *Keep*.
3. Beta 34 installs over earlier betas and keeps your settings. If you have one of the earlier hand-delivered test APKs, uninstall it first (different signing key).

Android 9 or newer, 64-bit ARM. On the first connect, allow notifications, the microphone and "no battery optimization" so receive keeps going in the background and PTT can transmit.
