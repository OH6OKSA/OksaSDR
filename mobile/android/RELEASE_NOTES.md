**OksaSDR for Android — beta 37.** A FlexRadio client for Android phones and tablets, built on the [AetherSDR](https://github.com/aethersdr/AetherSDR) engine: the same app as on the iPhone and iPad (TestFlight), from the same code.

### New in beta 37
- **Less battery:** the spectrum and waterfall are drawn by the graphics chip, and only what changed is redrawn: one new waterfall line instead of the whole picture each frame (thanks Mike VA3MW).
- **"2 analog" meters** on tablets: two analog meters side by side on each side, four readings while transmitting.
- **The app's memory** shows in the top row beside its CPU.

### Install or update
1. Download `OksaSDR-android-beta37.apk` below on the phone (about 150 MB).
2. Open it; allow installing from your browser or file manager when Android asks. If Chrome keeps the download waiting, open ⋮ → *Downloads* → *Keep*.
3. Beta 37 installs over earlier betas and keeps your settings. If you have one of the earlier hand-delivered test APKs, uninstall it first (different signing key).

Android 9 or newer, 64-bit ARM. On the first connect, allow notifications, the microphone and "no battery optimization" so receive keeps going in the background and PTT can transmit.
